# Waypoint Navigation Implementation Plan

## Goal
Implement autonomous waypoint navigation where:
1. Mobile RTK Control Module sends GPS waypoint via `/api/target`
2. Rover navigates to that waypoint autonomously
3. Rover avoids obstacles along the way
4. Code works identically in simulation and on real hardware

## Current State Analysis

### What Exists
- **HTTP Bridge** (`http_bridge.py`): Receives `/api/target` with lat/lon, stores in `self.target_waypoint`, but does nothing with it
- **GPS Bridge** (`gps_bridge.py`): Converts Gazebo XY → GPS lat/lon with configurable origin (37.7749, -122.4194)
- **Reactive Obstacle Avoidance** (`reactive_obstacle_avoidance.py`): VFH-based avoidance that publishes steering vectors to `/avoidance/safe_direction`
- **AprilTag Follower** (`apriltag_follower.py`): Good reference for state machine pattern with P-controller

### What's Missing
- GPS → local XY conversion for navigation
- Navigation controller that drives toward waypoint
- Integration between waypoint goal and obstacle avoidance
- Navigation status feedback to Mobile RTK Control Module

#### Architecture

```
Mobile RTK Module
    ↓ POST /api/target (GPS)
HTTP Bridge → /waypoint/target (NavSatFix)
    ↓
WaypointNavigator Node
├── Subscribes to:
│   ├── /waypoint/target (NavSatFix) - goal from HTTP bridge
│   ├── /gps/fix (NavSatFix) - current position
│   ├── /odom (Odometry) - heading and velocity
│   ├── /avoidance/safe_direction (Vector3) - from reactive avoidance
│   ├── /avoidance/critical_danger (Bool) - emergency stop
│   └── /rover/armed (Bool) - arm state
├── Publishes to:
│   ├── /cmd_vel (Twist) - velocity commands
│   └── /navigation/status (custom or String) - feedback
└── Uses same GPS origin as gps_bridge.py for coordinate conversion
```

#### State Machine

```
IDLE
  ├─ Waypoint received → ROTATING
  └─ Not armed → stay IDLE

ROTATING (turn toward waypoint)
  ├─ Facing waypoint (±15°) → NAVIGATING
  ├─ Obstacle danger → AVOIDING
  └─ Cancel/Disarm → IDLE

NAVIGATING (drive toward waypoint)
  ├─ Distance < arrival_threshold → ARRIVED
  ├─ Obstacle danger → AVOIDING
  ├─ Lost GPS fix → PAUSED
  └─ Cancel/Disarm → IDLE

AVOIDING (obstacle in path)
  ├─ Obstacle cleared → NAVIGATING
  ├─ Timeout → recalculate path
  └─ Cancel/Disarm → IDLE

ARRIVED (at waypoint)
  ├─ New waypoint → ROTATING
  └─ Auto-transition → IDLE (after 2 sec)

PAUSED (GPS lost or manual pause)
  ├─ GPS restored → NAVIGATING
  ├─ Resume command → NAVIGATING
  └─ Cancel/Disarm → IDLE
```

#### Key Parameters

```python
# Navigation thresholds
arrival_distance = 0.5      # meters - consider "arrived" within this distance
heading_tolerance = 15.0    # degrees - acceptable heading error to start moving
slow_approach_distance = 2.0 # meters - start slowing down

# Speed limits
max_linear_speed = 0.5      # m/s
max_angular_speed = 0.8     # rad/s
min_linear_speed = 0.1      # m/s - minimum movement speed

# Control gains
linear_kp = 0.5             # proportional gain for distance
angular_kp = 1.0            # proportional gain for heading

# GPS origin (MUST match gps_bridge.py)
origin_lat = 37.7749
origin_lon = -122.4194
```

#### GPS ↔ Local Conversion

```python
def gps_to_local(self, lat, lon):
    """Convert GPS to local XY (same logic as gps_bridge.py, inverted)"""
    lat_offset = lat - self.origin_lat
    lon_offset = lon - self.origin_lon

    x = lon_offset * self.meters_per_degree_lon
    y = lat_offset * self.meters_per_degree_lat
    return x, y

def local_to_gps(self, x, y):
    """Convert local XY to GPS"""
    lat = self.origin_lat + (y / self.meters_per_degree_lat)
    lon = self.origin_lon + (x / self.meters_per_degree_lon)
    return lat, lon
```

#### Control Logic

```python
def compute_velocity(self):
    # Get current position from odometry
    current_x, current_y = self.current_position
    current_heading = self.current_heading

    # Get target in local coordinates
    target_x, target_y = self.gps_to_local(self.target_lat, self.target_lon)

    # Calculate distance and bearing to target
    dx = target_x - current_x
    dy = target_y - current_y
    distance = math.sqrt(dx**2 + dy**2)
    target_heading = math.atan2(dy, dx)

    # Calculate heading error
    heading_error = self.normalize_angle(target_heading - current_heading)

    # P-controller for velocities
    angular_vel = self.angular_kp * heading_error
    angular_vel = clamp(angular_vel, -self.max_angular, self.max_angular)

    # Only move forward if roughly facing target
    if abs(heading_error) < math.radians(self.heading_tolerance):
        linear_vel = self.linear_kp * distance
        linear_vel = clamp(linear_vel, 0, self.max_linear)

        # Slow down near target
        if distance < self.slow_approach_distance:
            linear_vel *= (distance / self.slow_approach_distance)
    else:
        linear_vel = 0.0  # Rotate in place first

    return linear_vel, angular_vel
```

### Modifications to Existing Files

#### 1. `http_bridge.py` Changes

Add a new topic publisher for waypoint targets:

```python
# In __init__:
self.waypoint_target_pub = self.create_publisher(NavSatFix, '/waypoint/target', 10)

# In send_waypoint():
def send_waypoint(self, lat, lon):
    self.target_waypoint = (lat, lon)

    # Publish as NavSatFix for navigator
    msg = NavSatFix()
    msg.header.stamp = self.get_clock().now().to_msg()
    msg.latitude = lat
    msg.longitude = lon
    msg.status.status = 1  # Has fix
    self.waypoint_target_pub.publish(msg)

    self.mode = "autonomous"
    self.get_logger().info(f'Waypoint set: {lat:.6f}, {lon:.6f}')
    return True
```

## Simulation vs Real Hardware

### What's Identical (No Changes Needed)
- All ROS2 topics and message types
- State machine logic
- Control algorithms
- HTTP API interface
- GPS coordinate conversion math

### What Differs (Handled by Parameters)
| Aspect | Simulation | Real Hardware |
|--------|------------|---------------|
| GPS source | Gazebo plugin → gps_bridge | ZED-F9R → pyubx2 driver |
| GPS topic | `/gps/fix` (same) | `/gps/fix` (same) |
| Odometry | Gazebo diff_drive | Wheel encoders + IMU |
| Motor control | `/cmd_vel` → Gazebo | `/cmd_vel` → CAN → STM32 |

### `simulation_mode` Parameter Usage

```python
self.declare_parameter('simulation_mode', True)
self.simulation_mode = self.get_parameter('simulation_mode').value

# Differences:
# 1. Logging verbosity
# 2. Safety margins (larger in real world)
# 3. Speed limits (more conservative in real world)
```
